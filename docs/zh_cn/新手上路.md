# 新手上路

欢迎使用 Knights Auto Game！本文档将帮助你快速配置和启动 Knights Auto Game。

## 📦 一、下载与安装

### 1.1 下载

前往本项目的 [GitHub Releases](https://github.com/Knight-ts/Knights-web-windows/releases) 下载最新版本：

- **KnightsAutoGame-vX.Y.Z-win-x64.zip** — Windows 便携版（当前唯一发布形态）

> 本项目只提供网页版（浏览器控制台），不提供 MFAA / MXU / PiCLI 版本。

### 1.2 安装

1. 将压缩包解压到任意目录（路径不要含特殊字符）
2. 解压后应能看到：
   - `启动网页版.bat`（入口）
   - `webapp/`（网页后端与页面）
   - `agent/`（自定义识别与动作）
   - `resource/`、`table/`、`tasks/`
   - `python/`（内置 Python 3.12 运行时）
3. 不需要安装 .NET、VC_Redist 或额外的 Python

## 🔧 二、连接配置

### 2.1 模拟器连接（推荐）

#### 支持的模拟器

> ⚠️ **目前仅适配 MuMu 模拟器 12**，其他模拟器与真机未适配、未验证。

- ✅ MuMu 模拟器 12
- ❌ 雷电 / 夜神 / 蓝叠 / 逍遥 / 真机（未适配）

#### 配置步骤

1. **开启 ADB 调试**
   - 打开 MuMu「设置中心 → 其他」
   - 开启"ADB 调试"

2. **获取 ADB 端口**
   - MuMu 12 默认端口为 `16384`（部分版本为 `7555`）
   - 多开时逐个递增，在设置里查看实际端口

3. **在 Knights Auto Game 中配置**
   - 打开 Knights Auto Game
   - 选择"ADB"控制器类型
   - 输入 ADB 端口号（如 `127.0.0.1:5555`）
   - 点击"连接"测试连接状态

### 2.2 PC 端连接

#### 配置步骤

1. 确保游戏已安装并可以正常运行
2. 启动游戏客户端
3. 在 Knights Auto Game 中选择"Win32"控制器类型
4. 选择游戏窗口
5. 确保游戏窗口处于前台运行状态

## ⚙️ 三、分辨率设置

### 推荐分辨率

- **模拟器**：720x1280（竖屏）
- **PC 端**：保持游戏默认窗口大小

### 注意事项

- 分辨率过低可能导致识别失败
- 分辨率过高可能影响执行速度
- 建议使用整数倍缩放（如 720x1280、1080x1920）

## 🎮 四、首次运行

### 4.1 启动流程

1. **启动模拟器/游戏**
   - 确保模拟器/游戏已完全启动并进入主界面

2. **连接设备**
   - 在 Knights Auto Game 中选择对应的控制器
   - 确认连接成功（状态显示为绿色）

3. **选择任务**
   - 勾选需要执行的任务
   - 配置任务参数（如有）

4. **开始执行**
   - 点击"开始"按钮
   - 观察执行日志，确保正常运行

### 4.2 测试运行

建议先运行简单任务测试：

1. 选择"启动游戏"任务
2. 点击开始
3. 观察是否能正确识别并操作
4. 如有问题，查看日志文件排查

## 📝 五、任务说明

### 可用任务

| 任务名称 | 说明 | 适用场景 |
|---------|------|---------|
| 启动/关闭游戏 | 自动化启动和关闭游戏 | 日常使用 |

建议按照以下顺序执行任务：

1. 启动游戏
2. 执行日常任务（推月/推年）
3. 关闭游戏（可选）

## ❓ 六、常见问题

### 问题 1：无法连接设备

**解决方案**：

- 检查模拟器是否已开启 ADB 调试
- 确认端口号正确
- 尝试重启模拟器
- 检查防火墙是否阻止连接

### 问题 2：任务执行失败

**解决方案**：

- 检查分辨率是否符合要求
- 确保游戏语言为简体中文
- 查看日志文件 `debug/maa.log`
- 尝试重新连接设备

### 问题 3：OCR 识别失败

**解决方案**：

- 确保已下载 OCR 资源文件
- 检查游戏画面是否清晰
- 调整模拟器渲染设置
- 尝试降低分辨率
