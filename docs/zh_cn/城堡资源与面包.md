# 城堡资源记录 / 市场购买面包

两个城堡相关功能：一个负责记录资源并在低于阈值时暂停，一个负责按月份买面包。

两者都既是**独立任务**（任务列表里手动跑），也会在**月度循环**里按各自配置的月份自动执行。
手动运行时不看月份，立即执行。

---

## 1. 功能：城堡资源记录

entry：`Func_CastleResource`

### 读取什么

打开 城堡 页，OCR 右上角资源面板：

| 显示名 | 代码里的含义 | 示例 |
|---|---|---|
| 粮食存量 | 城堡粮食 | 101497 |
| 可调配量 | 城堡银币（按需求约定） | 5470688 |

数值识别兼容 `1,234`、`1.2k`、`3.4m` 这类写法。

### 记录到哪

`table/castle_resources.json`，只保留最近 200 条：

```json
{
  "records": [
    {
      "time": "2026-10-28 01:23:44",
      "year": 1838,
      "month": 6,
      "food": 101497,
      "silver": 5470688,
      "food_threshold": 100000,
      "silver_threshold": 0,
      "below": [],
      "action": "ok",
      "source": "manual"
    }
  ],
  "updated": "2026-10-28 01:23:44"
}
```

### 阈值与停止

- 「粮食阈值」「银币阈值」各一个，`0` = 不检查该项；
- 任一低于阈值：
  1. 平台推送（若配置了 `table/notify_config.json`）；
  2. 游戏内弹窗提示；
  3. 写 `temp/castle_resource_alert.json` 标记；
  4. `post_stop` 暂停任务。
- 年度任务里被暂停算**正常结束**（`success=True`），不是报错；处理完粮食/银币后重新运行即可。
- 手动运行本任务时只记录 + 提醒，不调用 `post_stop`；强制暂停只在月度循环里生效。

### 选项

| 选项 | 说明 |
|---|---|
| 城堡资源记录月份 | `0` = 不记录；`1-12` = 月度循环到该月自动记录 |
| 粮食阈值 | 粮食存量下限，`0` = 不检查 |
| 银币阈值 | 可调配量下限，`0` = 不检查 |

## 2. 功能：市场购买面包

entry：`Func_BuyBread`

### 路径

`城堡 → 市场 → 购买 → 选中「面包」→ 右下角「购买」→ 数量弹窗 → 确定`

### 数量

| 模式 | 行为 |
|---|---|
| 全部 | 点弹窗里的 `↑`（最大），等于市场当前剩余 |
| 指定数量 | 用 `+` / `−` 把数量调到目标值；超过市场剩余时按剩余封顶 |

数量在弹窗里是**只读文本**，只有 `−` / `+` / `↑` 三个按钮，所以指定数量较大时会点击较多次
（每次约 20ms，20000 次封顶；超过上限会退回「全部」并写日志）。

### 无货

面包市场库存为 0 时：

- 购买按钮是灰的，点「购买」不会弹数量窗；
- 记录一条 `status: "no_stock"` 到 `table/bread_purchases.jsonl`；
- 跳过，不报错，下个月再试。

### 购买记录

`table/bread_purchases.jsonl`，一行一条：

```json
{"time": "2026-10-28 01:40:00", "year": 1838, "month": 7, "item": "面包", "quantity": 500, "cost": 2000, "remaining_before": 1200, "mode": "num", "source": "yearly", "status": "ok"}
```

### 选项

| 选项 | 说明 |
|---|---|
| 面包购买月份 | `0` = 不购买；`1-12` = 月度循环到该月自动购买 |
| 面包购买数量 | 全部 / 指定数量 |
| 面包指定数量 | 指定数量模式下买几个，默认 100 |

---

## 月度循环里的执行顺序

每月流程最前面（`process_single_month`，处理节日之前）：

1. 如果当前月 == 配置的记录月份 → 城堡资源记录（可能暂停年度任务）；
2. 如果当前月 == 配置的购买月份 → 购买面包；
3. 继续原来的节日 / 接任务 / 战斗流程。

两个功能识别失败只写日志，不会拖垮整个月度循环；只有「资源低于阈值」会主动暂停。

## 实现位置

- `resource/base/pipeline/castle.json`：城堡页、市场、购买弹窗的 OCR / 点击节点；
- `agent/action/fight/castle_resource_processor.py`：资源读取、记录、阈值暂停；
- `agent/action/fight/bread_purchase_processor.py`：面包购买、数量调整、无货跳过；
- `agent/action/fight/fight_processor.py`：`_run_castle_features()` 月度循环接入。

## 注意

- 「可调配量」按需求作为城堡银币；市场买面包扣的是画面左下角的个人银币，两者不是同一个数。
- 面包市场库存会刷新；库存为 0 时功能只记录无货，不会等待刷新。
- 购买弹窗的坐标基于 720×1280（MuMu 12）；换分辨率需要同步改 `castle.json`。
- 暂停标记 `temp/castle_resource_alert.json` 不会自动删除，处理完资源后可手动清掉。
